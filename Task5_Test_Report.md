# Task 5: Automated UI Tests for an E-Commerce Checkout Flow

## 1. Objective
To automate the e-commerce checkout process using Python and Selenium WebDriver and verify page transitions, form validation, and order confirmation.

## 2. Application Under Test
Website: SauceDemo
URL: https://www.saucedemo.com/

## 3. Tools Used
- Python
- Selenium WebDriver
- Visual Studio Code
- Google Chrome

## 4. Test Scenarios
1. Verify successful login.
2. Verify that a product can be added to the shopping cart.
3. Verify navigation to the checkout information page.
4. Verify validation when required checkout information is missing.
5. Verify navigation to the checkout overview page after entering valid information.
6. Complete checkout and verify the order confirmation message.

## 5. Test Execution
The automation script was executed locally using Python, Selenium WebDriver, and Google Chrome.

## 6. Test Results
All six automated test checks passed during execution.

## 7. Conclusion
The automated tests successfully verified the main e-commerce checkout flow, including login, adding a product to the cart, required-field validation, checkout page transitions, and order confirmation.
