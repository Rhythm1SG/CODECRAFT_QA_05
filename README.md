# CODECRAFT_QA_05
## Automated UI Tests for an E-Commerce Checkout Flow

### Project Overview
This project automates the e-commerce checkout process using Python and Selenium WebDriver. The tests verify login, adding products to the shopping cart, checkout form validation, page transitions, and order confirmation.

### Application Under Test
- **Website:** SauceDemo
- **URL:** https://www.saucedemo.com/

### Technologies Used
- Python
- Selenium WebDriver
- Google Chrome
- Visual Studio Code

### Test Scenarios
1. Verify successful login.
2. Verify that a product can be added to the shopping cart.
3. Verify navigation to the checkout information page.
4. Verify validation when required checkout information is missing.
5. Verify navigation to the checkout overview page.
6. Verify successful order completion and confirmation message.

### Test Execution
The automated test script was executed locally using Python, Selenium WebDriver, and Google Chrome.

**Result:** All six test checks passed during execution.

The automated tests verified the main checkout workflow, including cart operations, form validation, checkout page transitions, and order confirmation.
